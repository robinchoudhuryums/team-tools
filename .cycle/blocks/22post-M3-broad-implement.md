REGRESSION RISKS:
- A diagram change now needs a CODE deploy (the partial is code), while text changes need only an import — documented in the exporter, the README and the partial's own header; the Node harness fails if a diagram changed and the partial was not regenerated.
- The first import with images uploads ~160 files to Drive; with the 4-minute budget it may take two runs (the dialog says "press Import again"; the sections are in after the first).
- A replaced image leaves its old Drive file in the KB Images folder (never overwritten, never deleted) — small, harmless, and a follow-on.
- An image is ~0.5–100 KB as a data URL; a part with many photos costs one or two getManualImages calls on first view (cached six hours by hash afterwards).
- The partial adds ~139 KB to every page load (gzip makes it far smaller on the wire); chosen over a lazy RPC so diagrams draw synchronously with no fixture and no server read.

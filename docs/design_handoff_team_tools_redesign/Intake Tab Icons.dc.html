UMS Team Tools · Icon study

Intake tab icons — what's possible & what to use

Icons live in a single registry (script_icons.html): each is a named key mapping to inline SVG path data, drawn on a 24×24 grid with stroke="currentColor" so every glyph inherits its surrounding text color — light mode, dark mode, and status tints all work automatically. ~50 ship today. Your options are (1) reuse an existing key, or (2) add a new one — a single line of SVG path data in the same Lucide-style stroke vocabulary.

03 · The glyphs to add to the registry
Four new keys, each one line of path data in the existing stroke style.
PPD
clipboardList
The patient-profile questionnaire. Alt: clipboardCheck (✓ instead of lines) to emphasize the recommendation.
PMD
accessibility
Power-mobility device account. The accessibility figure reads as mobility instantly and renders cleanly at 15px (a literal wheelchair gets muddy that small).
PAP
airflow
CPAP / sleep-therapy account. Airflow lines = breathing/air pressure. Alt: moon (already exists) for "sleep".
Sent
outbox
An open tray with items lifting out — reads as "things I've sent." Frees the paper-plane up entirely. Alt: send (paper-plane) or mailCheck.

What changed
  • Parse the lead — the *Name / *Phone / *Email / *State / *Zip / *Source lines become a clean field grid, not raw text.
  • Separate the ask from the sender's signature and the Google Groups footer — the boilerplate collapses behind a toggle (and "Raw email" is still one click away).
  • Collapsed default is a tidy one-line summary (name · need · phone · age) so the list scans; expand for full details.
  • Phone & email are tappable; phone is surfaced even when collapsed (it's the point of the task).
  • Wider card fills the column instead of a narrow strip; status + age as a chip.
Parsing note: these leads follow a fixed *Field: template, so a few regexes extract the grid reliably; fall back to the raw body when a field is absent.
